# Radmir Monitor Offline

Локальный счётчик нормы для администраторов RADMIR RP. Приложение читает `chatlog.txt`, считает репорты, наказания и время в игре, показывает дневную статистику и историю. Данные и настройки хранятся на компьютере.

## Офлайн-режим

- Для подсчёта и просмотра статистики интернет не нужен.
- История, нормы, цели и настройки сохраняются локально в `%LOCALAPPDATA%\RadmirMonitor`.
- Нет синхронизации с API, проверки и загрузки обновлений или загрузки плагинов.
- QR-страница телефона — необязательный локальный просмотр по домашней/офисной сети. Она обслуживается самим приложением и не использует внешний сервер. Её можно выключить в разделе «Норма».

## Запуск готового приложения

Скачайте `RadmirMonitor.exe` из опубликованного релиза и запустите его. Обычная сборка требует Windows x64 и .NET 8 Desktop Runtime. Если runtime не установлен, используйте self-contained сборку, включающую его.

В «Настройках» укажите ник администратора и путь к `chatlog.txt` (или нажмите «Авто»), затем включите мониторинг. Счётчик начинает читать новые строки файла с текущего конца, поэтому старые записи не добавляются повторно.

## Сборка из исходников

Нужны Windows 10/11 и .NET 8 SDK. В корне репозитория выполните:

```bat
build.bat
```

Готовый framework-dependent файл появится в `publish\RadmirMonitor.exe` и требует .NET 8 Desktop Runtime.

Чтобы собрать один self-contained EXE, который включает .NET Runtime:

```bat
build-selfcontained.bat
```

Результат будет в `publish-selfcontained\RadmirMonitor.exe`. Self-contained файл заметно больше. NuGet-пакеты восстанавливаются во время первой сборки; работа самого приложения после сборки не требует доступа к интернету.

## Локальные данные

В `%LOCALAPPDATA%\RadmirMonitor` находятся:

- `settings.json` — ник, пути и параметры интерфейса;
- `local_data.json` — история событий и учёт онлайна по дням;
- `monitor.log` — журнал работы приложения.

Чтобы перенести данные на другой компьютер, закройте приложение и скопируйте эту папку. Автозапуск Windows и разрешение доступа к LAN-странице телефона настраиваются отдельно в Windows.
