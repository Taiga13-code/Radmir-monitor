# Radmir Monitor

**Счётчик нормы для администраторов RADMIR RP.** Следит за `chatlog.txt` и показывает репорты, наказания, онлайн и историю за последние 31 день.

[Скачать готовый RadmirMonitor.exe](https://github.com/Taiga13-code/Radmir-monitor/releases/latest/download/RadmirMonitor.exe) · [Все релизы](https://github.com/Taiga13-code/Radmir-monitor/releases)

## Быстрый старт

1. Скачай и запусти `RadmirMonitor.exe`. Устанавливать .NET отдельно не нужно.
2. Открой **Настройки**, укажи свой ник и выбери `chatlog.txt`. Кнопка **Авто** попробует найти файл сама.
3. Нажми **Сохранить настройки**, затем **Запустить** на главной.

Готово: новые действия администратора появятся в статистике и истории. Старые строки из файла повторно не засчитываются.

## Что умеет

- Считает репорты, наказания и время в игре.
- Показывает статистику за день, историю за 31 день и поиск по наказаниям.
- Позволяет настроить цели и компактный оверлей поверх игры.
- При желании открывает норму на телефоне в локальной сети через QR-код.

## Всё остаётся на твоём компьютере

Монитор работает без аккаунта и интернета. Он не отправляет статистику на сервер, не скачивает обновления и плагины. Телефон подключается только к локальной сети, пока приложение запущено.

Настройки, история и журнал находятся в `%LOCALAPPDATA%\RadmirMonitor`. Чтобы перенести данные на другой компьютер, закрой приложение и скопируй эту папку.

## Сборка из исходников

Для Windows и .NET 8 SDK:

```bat
build.bat
```

Файл появится в `publish\RadmirMonitor.exe`; для него нужен .NET 8 Desktop Runtime. Чтобы собрать отдельный EXE со встроенным .NET, запусти:

```bat
build-selfcontained.bat
```

Результат будет в `publish-selfcontained\RadmirMonitor.exe`. Первая сборка восстанавливает NuGet-пакеты из интернета, но готовое приложение работает офлайн.
